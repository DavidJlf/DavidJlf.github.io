# Linfeng Jiang - Personal Research Website

A lightweight, responsive personal research website designed for GitHub Pages.

## Preview locally

Open `index.html` directly, or run a local static server from this directory:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

1. Create a public repository named `<your-github-username>.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, and use the repository root.
5. The site will be available at `https://<your-github-username>.github.io`.

## Update later

- Edit the page content in `index.html`.
- Adjust the visual system in `styles.css`.
- Replace `assets/Linfeng_Jiang_Resume.pdf` whenever the résumé changes.
- Add GitHub, LinkedIn, or Google Scholar links after those profile URLs are confirmed.
